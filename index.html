⚙ KI-Verbindung & Bildgenerator einrichten

Erstelle einen persönlichen API-Schlüssel auf OpenRouter. Die App verwendet ihn direkt von diesem Gerät. Der Schlüssel wird nur in diesem Browser gespeichert, ist aber auf gemeinsam genutzten Geräten oder bei manipulierten Seiten nicht sicher. Nutze einen Schlüssel mit kleinem Ausgabenlimit. Es können Gebühren entstehen.

Prüfe verfügbare Modelle und deren Preise auf OpenRouter. Die Bildgenerierung hängt vom ausgewählten Modell ab. Für eine dauerhaft sichere App sollte die API über einen eigenen Server laufen.
